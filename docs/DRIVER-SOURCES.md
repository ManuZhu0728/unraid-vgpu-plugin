# 下载源格式

## 自动匹配

“下载地址”接受 GitHub 或 GitLab 仓库、Release 页面和 TXZ 的 HTTPS 直链。插件从 URL 识别平台，
按运行内核匹配包。默认优先已装驱动版本，否则选择匹配内核的最高版本；同一驱动的构建号按数字排序。
高级设置可固定驱动版本和构建号。

新式 Release 的标签是内核，例如 `6.18.58-Unraid`。旧标签如 `v6.18.58-595.58.03` 仍可读取。
GitHub 私有附件通过资产 API 获取，GitLab 私有源使用同源认证。跨域下载时移除原站 Token。

## 学校 GitLab

API Token 可查找 Releases。带 `read_package_registry` 的 Deploy Token 可按已知版本定位 Generic 包。
未固定构建时查找 `build/v{kernel}-{driver}`；构建 N > 1 默认使用 `build/v{kernel}-{driver}-buildN`。
需要其他构建时，在高级设置固定版本和构建号，或粘贴 Generic 包链接。

```text
/api/v4/projects/<ID或编码路径>/packages/generic/build/<版本>/<文件名>
```

## 驱动仓库发布布局

| 内容 | 示例 |
| --- | --- |
| 按内核汇总的 Release | `6.18.58-Unraid` |
| 构建 1 的 Generic Package 版本 | `v6.18.58-595.58.03` |
| 构建 2 的 Generic Package 版本 | `v6.18.58-595.58.03-build2` |
| 共享构建输入 | `inputs-595.58.03-r1` |

包名为 `nvidia-<驱动>-<内核>-Unraid-<构建>.txz`。构建号是不带前导零的正整数。
发布带 `experimental` 等本地标记的 TXZ 时，先通过驱动发布器生成标准公开名。
自定义标签或 Generic 版本模板可用 `{kernel}`、`{driver}`、`{build}`。

## 选择与缓存

手动下载及后台准备均显示阶段、已接收字节、可用时的总大小和平均速度；总大小未知时不显示虚构百分比。
进度及取消经过原生鉴权和 CSRF 检查，但不等待下载持有的配置锁。刷新页面可以重新查看活动任务。
“取消下载/取消准备”只请求终止该任务自己的网络传输，清理未完成临时文件，保留已有缓存、启动构建和运行中的 GPU。
提交已校验结果期间不可中断。收到“下载已取消”才代表任务已确认停止；断网、鉴权失败或回执丢失不能当作已取消。

版本列表按完整包名区分构建。回退时核对固定版本和构建设置。
缓存回执记录内核、驱动、构建号、来源及 MD5。旧回执没有构建号时，仅 `-1.txz` 按构建 1 读取。
同名包的 MD5 发生变化时，缓存保留原件。

## 本地文件

上传需要 TXZ 及发布者提供的对应 MD5。MD5 文件须非空且不超过 4 KiB，支持裸哈希、
`hash  filename` 和 `hash *filename`。校验通过后才检查归档与模块并写入缓存。单文件 CLI 导入也需要 MD5 路径。

浏览器以 URL 编码表单传送 base64url 分块，原始数据每块最多 1 MiB、总量最多 2 GiB，
单块大小还受 PHP `post_max_size` 限制。确认取消或已知校验失败时清理该会话。
断网、鉴权失效或回执丢失时，先重新打开页面核对缓存，再决定是否重试。
