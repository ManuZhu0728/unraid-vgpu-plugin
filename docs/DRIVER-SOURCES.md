# 下载源格式

## 自动匹配

页面的“下载地址”支持仓库、Release 页面和 TXZ 文件直链。平台由 URL 识别；
当前运行内核决定包名。高级设置可以固定驱动版本及构建号，默认优先已安装版本，其次是最高匹配版本。
Releases 中同一驱动的构建按数字排序，例如构建 10 高于构建 2。

新式 Release 使用内核作为标签：

```text
6.18.58-Unraid
├── nvidia-580.159.03-6.18.58-Unraid-1.txz
├── nvidia-580.159.03-6.18.58-Unraid-1.txz.md5
├── nvidia-595.58.03-6.18.58-Unraid-1.txz
├── nvidia-595.58.03-6.18.58-Unraid-1.txz.md5
├── nvidia-595.58.03-6.18.58-Unraid-2.txz
└── nvidia-595.58.03-6.18.58-Unraid-2.txz.md5
```

旧的 `v6.18.58-595.58.03` 标签仍可读取。GitHub 私有附件通过资产 API 下载；
GitLab 私有源使用同源认证。MD5 支持裸哈希及“哈希 + 文件名”两种格式。

## 学校 GitLab

仓库链接加 API Token 可以查找 Releases。Deploy Token 只允许读 Package Registry：

- 未固定构建时，Generic 定位使用构建 1 的 `build/v{kernel}-{driver}`。
- 固定构建 N > 1 时，默认位置是 `build/v{kernel}-{driver}-buildN`；不会逐个猜测远端构建号。
- 其他版本或构建可在高级设置指定，或直接粘贴 Generic API 的 TXZ 下载链接。
- Generic API 链接格式为 `/api/v4/projects/<ID或编码路径>/packages/generic/build/<版本>/<文件名>`。

自动识别只在同一仓库内选择访问方式。认证和网络错误会直接显示，跨域下载不会携带原站 Token。

## 驱动仓库发布布局

驱动发布器按内核汇总 Release，每个构建保留自己的包地址：

| 内容 | 格式 |
| --- | --- |
| 内核汇总 Release | `6.18.58-Unraid` |
| 原有 Generic Package 版本 | `v6.18.58-595.58.03` |
| 构建 2 的 Generic Package 版本 | `v6.18.58-595.58.03-build2` |
| 共用构建输入 Release | `inputs-595.58.03-r1` |

汇总页链接 TXZ/MD5，多个驱动和构建采用合并保留。构建输入修订号 `r1` 与 TXZ 构建号独立，
只调整打包流程时可继续复用同一份输入。插件不会重命名或修改远端 Release。

公共包名为 `nvidia-<驱动>-<内核>-Unraid-<构建>.txz`，构建号为不带前导零的正整数。
带 `experimental` 等标记的本地构建文件应经驱动发布器规范命名后提供给插件。
自定义标签或 Generic 版本模板可使用 `{kernel}`、`{driver}`、`{build}`。

## 选择与缓存

版本列表按完整包名选择，因此同一个 `595.58.03` 的构建 1 和构建 2 不会混淆。
高级设置中的固定版本和构建号用于开机安装及升级策略；需要回退时，也应调整相应固定设置。

缓存回执记录内核、驱动版本、构建号、来源及 MD5。旧版未记录构建号的回执，仅在文件名为
`-1.txz` 时按构建 1 读取。构建 2 及以后必须有与文件名一致的构建号。
同名包校验值变化时，不会覆盖原缓存。

## 本地文件

浏览器按最多 1 MiB 分块上传，后端在独立临时目录拼接，完成后调用与在线下载相同的归档检查。
附带 MD5 时校验文件内容；未附带时记录本地计算值。取消或校验失败会清理该上传会话。
