# Unraid vGPU Manager 2026.11.02.5 — Alpha 3

- 新增“跟随 Unraid 更新驱动”开关。
- 首次启用先缓存当前内核驱动，系统更新后准备目标内核包，并发送进度和结果通知。
- 新增开机驱动安装及版本复核，支持后续普通重启从缓存恢复。
- 自动选择保持 NVIDIA 驱动分支，保留原内核缓存。
- 安装前检查启动入口和 GPU/VFIO 占用；失败保留记录供页面查看。
- 包含简化下载配置、按内核 Release 匹配和本地分块导入。

新功能默认关闭。启用开机安装前，将原驱动插件/User Scripts 迁移到本插件。
配置方法见 [系统升级联动](../OS-UPGRADES.md)。
