# Unraid vGPU Manager 2026.11.02.3 — Alpha 1

首个公开测试版。插件管理程序公开下载，私有驱动源在安装后配置，不需要在 PLG 中携带 token。

## 已提供

- GitHub Releases、GitLab Releases 和 GitLab Generic Package 下载源。
- 独立凭据保存、来源绑定、跨源跳转清除认证，页面和日志不回显 token。
- 按内核匹配驱动并被动校验 MD5、归档和模块；只写缓存，不安装 NVIDIA 驱动。
- 统一配置和设备管理后端；运行管理默认关闭，拒绝接管旧插件/User Script 和未知 GPU 占用。
- 在线 PLG、硬件无关测试和可重复的插件打包流程。

## 安装

在 Plugins → Install Plugin 使用：

```text
https://raw.githubusercontent.com/ManuZhu0728/unraid-vgpu-plugin/main/unraid-vgpu-manager.plg
```

附件仅三个：`unraid-vgpu-manager.plg`、插件 TXZ、同名 MD5。
不包含 NVIDIA 驱动、底包、旧预览或 SHA256 文件。

## 重要限制

- 尚未在真实 Unraid WebGUI 和 GPU 上验收。无硬件模拟测试不能代替实机测试。
- 安装插件不等于迁移启动链；已有 novidio 插件/User Scripts 时不要启用新运行管理。
- 不支持从缓存安装/激活驱动、自动停 VM/Docker、热重载 NVIDIA 栈。
- 不修复现有 NVIDIA MMIO 内核警告，不改变现用驱动包。
- 凭据和配置备份属于敏感文件；Unraid FAT 闪存不能只依赖 chmod 保密。

生产服务器保持现状；后续单独安排备份、唯一启动入口迁移和实机验收。
