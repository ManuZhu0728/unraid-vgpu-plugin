# Unraid vGPU Manager 2026.11.15.1 Alpha 8

本版准备接替旧驱动插件与 User Scripts，重点完善驱动包选择、开机安装和系统升级后的恢复。
NVIDIA 驱动仍从你配置的下载源获取，不包含在插件中。

## 更新内容

- 按内核、NVIDIA 版本和打包构建号选择驱动，同一版本的 build 1、2 等可分别缓存和选择。
- 独立设置“开机恢复驱动”“系统升级预下载”和“vGPU 初始化”。离线导入也能用于开机恢复。
- 升级时保留 Docker、Toolkit、UnlockRS、许可及模块参数配置，并核验包记录和全部目标模块。
- 按内核保留已核验的包记录，系统回退后可使用对应的缓存；不会自动跨 NVIDIA 分支切换。
- 检查旧插件、启用的 User Scripts、go 及固定路径引用，显示冲突入口；普通监测命令不算初始化。
- 安装失败或超时后阻止本次开机再次安装，保留诊断和配置备份。

## 升级与接管

先更新插件、准备驱动缓存并保存现有设备的 UUID、PCI 和 profile。原来由旧插件与脚本启动
的机器，在维护窗口停用旧入口后再开启新插件的开机管理，通过重启完成首次接管。
旧可用包和旧配置保留用于恢复。详细步骤见
[首次迁移与恢复](https://github.com/ManuZhu0728/unraid-vgpu-plugin/blob/main/docs/OS-UPGRADES.md#首次迁移)。

三个开关新安装时默认关闭，已有配置继续保留；旧版开启的升级联动会转换为独立的预下载
与开机恢复设置。运行中更新插件不热替换已加载的驱动。
