# Unraid vGPU Manager 2026.11.16.2 Alpha 13

修复已有设备详情与 VM XML 展开时挤压列表、拉宽按钮和打乱操作位置的布局问题。

## 更新内容

- 将只读展开正文与列表列宽、操作按钮布局分离；查看详情或 XML 不改变新增草稿。
- 保留固定操作区、独立设备身份和 XML 复制；多个设备及长内容不会互相挤压列表。
- 补充展开/收起、窄屏、多行设备、长 profile 和 XML 的浏览器回归，并验证旧布局负对照。
- 保留新增保存成功/失败处理、设备动作的禁用条件、双 CSRF 和确认提示。

不包含重新配置、运行态接管、驱动更新、启动逻辑修改或其他表单提交方式改造。

## 升级与验收

在 Unraid 插件页检查更新并升级到 `2026.11.16.2`，重新打开 vGPU 管理页；无需为这次界面更新重启。
分别展开详情、VM XML，再组合展开，确认操作按钮不被拉长、不掉到正文后面，其他设备列宽保持稳定。
缩窄浏览器后检查内容仍可阅读或在局部区域滚动，XML 可复制，新增表单输入不因查看而改变。

离线测试使用真实 PHP 页面和官方 WebGUI 7.3.4 CSS/字体，不替代实际 Unraid 浏览器验收。
本次发布不包含 NAS 部署、GPU/服务操作或重启；旧版发布附件保留。
