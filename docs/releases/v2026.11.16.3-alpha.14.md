# Unraid vGPU Manager 2026.11.16.3 Alpha 14

新增已下载驱动管理，并修复下载期间插件正文空白的问题。

## 更新内容

- “驱动管理 → 已下载驱动”列出各内核的驱动版本、构建号、大小和保护原因。
- 未被引用的包可确认删除 TXZ 和同名 MD5，不卸载运行中的驱动，不更改选包/启动配置。
- 保护当前选中、升级预下载与基线、上次成功安装及内核回退记录引用的包；异常记录禁用删除。
- 删除通过共享事务锁重新核对引用，拒绝过期页面、越界路径和软/硬链接；失败不误报完整成功。
- 下载采用同页异步请求，显示不定进度条及耗时，校验成功后原地更新缓存和保护状态。
- 保留未保存的地址/Token 草稿，不执行响应 HTML；断网或超时先提示核对，不自动重试。

当前下载后端没有实时字节进度，因此不显示估算百分比。
文件删除不可本地撤销，需要恢复时请从原来源重新下载或上传。
本版不改开机选包、驱动安装、GPU/服务操作或设备重新配置逻辑；旧包不会自动清理。

## 升级与验收

在 Unraid 插件页检查更新，升级到 `2026.11.16.3` 后重新打开驱动管理页，无需为界面功能主动重启。
确认缓存列表显示构建号与保护原因；只选择不再需要且未被引用的包测试删除。
下载时页面应保持可见，完成后缓存与当前选中保护标记同步更新。

硬件无关、localhost HTTP 及官方 WebGUI CSS/字体下的浏览器测试通过，实际 Unraid 7.3.4
仍由用户验收。本次发布不连接 NAS、不代为删除缓存、不重新打 NVIDIA 驱动包；保留旧版发布附件。
