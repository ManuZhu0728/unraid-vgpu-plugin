# Unraid vGPU Manager 2026.11.15.2 Alpha 9

本版仅调整 vGPU 设备操作按钮的布局，便于在 Unraid 7.3.4 上继续验收插件接管。
不包含 NVIDIA 驱动，不改变已有设备或驱动启动策略。

## 更新内容

- 统一“编辑、启动、停止、移除”按钮的外层布局，消除表单 inline 行盒引入的对齐差异。
- 保留按钮禁用条件、独立 POST、CSRF 校验及停止/移除确认提示。
- 页面最大宽度、profile 可用性判断、驱动安装和 vGPU 初始化逻辑均保持不变。

## 升级与验收

在 Unraid 的插件页检查更新，升级到 `2026.11.15.2`，随后刷新设置页面核对按钮。
已有设置、设备 UUID 和缓存继续保留；无需重新安装驱动或重新添加设备。

先在 7.3.4 完成接管及普通重启验收，再测试 7.4 的驱动预下载与冷启动恢复。
首次接管仍需在维护窗口停用 novidio 和旧 vGPU User Scripts 启动入口，保留旧包与配置。
更新插件不等于完成接管；应核对本次开机安装记录、设备恢复和实际 GPU 工作负载。

## 验证范围

本地硬件无关回归通过。离线浏览器使用官方 Unraid 7.3.4 CSS 和字体，覆盖黑白主题、
两档字号、3840/1920/1280/768/390 CSS 像素视口及三种设备状态，共 60 组布局用例。
恢复旧 CSS 的负对照能触发布局断言失败。

尚未在用户 NAS 上验证此次界面修复，也未完整复现截图中仅灰色按钮的具体偏移。
Unraid 接管、GPU 工作负载、7.4 升级及回退仍需分别实机验收。
