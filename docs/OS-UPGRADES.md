# 随 Unraid 更新驱动

## 使用

保存下载地址和 Token，开启“系统升级预下载”。助手会先缓存当前内核的驱动，
随后监听系统升级。开启“开机恢复驱动”后，插件才会在后续启动安装缓存包。
升级 Unraid 后，等待 **NVIDIA vGPU Manager 的“新内核驱动已准备”通知**，再按正常流程重启。

两个开关独立：只预下载可以先验证下载源；只开机恢复可以使用本地上传包，不访问仓库。
关闭预下载不会关闭驱动恢复，也不会删除已准备好的缓存。

页面“升级准备”显示准备状态、目标内核和驱动版本。缺包或网络失败时会通知，
后台每 15 分钟重试；“检查升级准备”可立即再检查。修改地址或 Token 后也会重新检查。

默认跟随已选择的 NVIDIA 分支，不自动从 R580 跳到 R595。固定完整驱动版本时，
只下载该版本对应的新内核包；固定构建号时也必须匹配该构建。
Releases 中未固定构建时选择该驱动的最高构建；当前内核已有选择不会被后台检查替换。
Generic 定位规则见[下载源格式](DRIVER-SOURCES.md)。

首次开启恢复时，已明确选中的当前内核包优先于正在运行的驱动来确定分支。
恢复已经开启后，要从 R595 切换到 R580 等另一分支，请在高级设置固定目标驱动版本，
或导入目标包后关闭并重新开启“开机恢复驱动”；新选择在下次重启安装。

## 首次迁移

驱动恢复、升级预下载和 vGPU 初始化分别设置。驱动恢复负责安装缓存，预下载负责网络获取，
vGPU 初始化负责服务和设备。只使用宿主机或 Docker 的 GPU 功能不需要启用 vGPU 初始化。
使用原插件或 User Scripts 的机器，需要先整理为一个启动入口，再安排第一次重启。
插件会识别冲突的旧驱动插件、脚本及 GPU/VFIO 占用。

开启预下载会启动下载助手；开启驱动恢复只保存启用时的 boot ID，安装发生在后续开机。
原缓存保留，便于随系统回退使用。

旧版设置读取时自动转换为 schema 2：原 `upgrade.enabled=true` 对应预下载和驱动恢复均开启，
原启用 boot ID 转移至 `driver.enabled_boot_id`。页面查看不写文件；下次保存时写入新结构。
已经明确保存的 `driver.enabled=false` 不会因为预下载开启而被重新启用。

## 执行顺序

```text
开启预下载 → 缓存当前内核驱动
系统更新 → 读取目标内核 → 下载并校验 → 通知准备完成
开启驱动恢复后的重新开机 → 配置备份 → 安装匹配包 → 配置恢复与版本复核
启用 vGPU 初始化时 → 恢复 vGPU → Docker/VM 启动
```

Unraid 的 `/usr` 内容在重启后重建，因此普通重启也需要从持久缓存恢复驱动。
安装器记录 Linux boot ID，区分重新开机与运行中更新插件；同一次启动失败后不重复安装。
安装或校验失败会保留缓存和历史成功记录，并停止后续 vGPU 初始化。

同一个 NVIDIA 版本可能有不同打包构建。`modinfo` 的版本和内核匹配，不足以证明选中的构建已安装。
插件结合本次启动的成功安装回执识别构建；由其他入口加载、构建尚未确认时显示“等待重启安装所选构建”。

## 安装期间保留配置

安装器在调用包管理器前，备份已有的 Docker、NVIDIA Container Runtime、GRID 许可、
UnlockRS 和 `/etc/modprobe.d/nvidia.conf` 配置，包括已有 `.new`、许可文件和受支持的软链接目标。
安装后恢复原值，Docker 仅合并 `runtimes.nvidia`，保留镜像源、其他 runtime 和权限。
之后若启用了 vGPU 初始化，其 UnlockRS 设置会按插件保存的配置应用。

普通安装失败或后续检查失败会恢复原配置；这不是整个驱动包的回滚。安装超时时，
因为后台安装进程可能仍在执行，会保留备份并提示处理，不与它并发回写配置。
事务目录位于 `/var/run/unraid-vgpu-manager/install-transactions/`。失败后如需保留以便排查，
应在重启前备份；其中可能包含许可凭据，不要公开上传。

## 文件

| 路径 | 用途 |
| --- | --- |
| `settings.json` 的 `driver` | 开机恢复开关和启用时的 boot ID |
| `settings.json` 的 `upgrade` | 预下载开关和驱动分支 |
| `upgrade-state.json` | 当前准备任务和目标包回执 |
| `driver-state.json` | 开机安装结果及成功回执 |
| `packages/<内核>/` | 各内核驱动缓存 |
| `/var/log/unraid-vgpu-manager-upgrade.log` | 助手运行摘要 |

设置、状态回执和缓存位于 `/boot/config/plugins/unraid-vgpu-manager/`。
助手使用独立 PHP 进程，不覆盖系统共享的 `plugin_update_helper`。

## 开发验证

运行 `bash tests/run-tests.sh`。测试使用临时文件、模拟下载源和安装命令，覆盖准备、
新内核重启、后续普通重启、重复启动、缺包、占用和安装失败。实机升级测试需在发布后
安排维护窗口；构建机不安装 NVIDIA 驱动。
